# P&C Trade + Intelligence Regional Dashboard Upgrade

This upgrade carries the regional-dashboard concept into the two mature applications rather than adding another application.

## P&C Trade
The Overview is now a Trade Operating Picture with persistent Region + Focus Area context.
The selected context drives:
- current developments
- operational disruptions
- infrastructure/assets
- companies/entities
- routes/corridors
- vessels/mobile assets
- projects/future capacity

The product lens remains movement and commerce. Security appears when it affects trade.

## P&C Intelligence
The Operating Picture now opens with persistent Region + Focus Area context.
The selected context drives:
- what changed
- threat/event-family picture
- incident map
- priority incidents
- monitoring & indicators
- assessment triggers
- the downstream latest/priority operating picture

The product lens remains security intelligence. Routine commercial development remains in Trade.

## Important
No database migration is introduced. These builds use the existing canonical data, regional definitions, event routing, source/evidence handling and map helpers already present in the two applications.

The regional dashboard is a product context, not a fifth application.
