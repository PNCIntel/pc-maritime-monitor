# v3.0.7 — Trade Incident Card

Changes to the P&C Trade System only:

- Removed the explanatory banner referring users to the separate P&C Intelligence product.
- Trade incident cards now display:
  - date / event type / severity / location
  - incident title
  - concise description
  - operational impact
  - trade / commercial impact
- The linked-entity section is now labelled `Commercially connected network`.
- Port, company, vessel and system relationships remain directly beneath the incident.
- P&C Intelligence remains a separate product and its interface is unchanged.

This is a presentation-layer update; the shared Excel data model is unchanged.
