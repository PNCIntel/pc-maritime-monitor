# Model Validation Questions

The seed should be able to answer these without inventing or duplicating canonical records:

1. Which PGSA-listed vessels are already canonical vessels in the database?
2. Which listed vessels have modeled owner/operator relationships?
3. Which STS counterparties create possible secondary PGSA exposure?
4. Which official Japan/Korea/India MARSEC events are present and what was the operational impact?
5. Which security events also create commercial/trade consequences?
6. Which assets are owned or operated by AD Ports Group?
7. What investments and CAPEX records are linked to AD Ports Group?
8. What historical AD Ports market-price observations exist?
9. Which ports/assets in the sample have active or historical disruption events?
10. Which records are still provisional and need stronger ownership/registry verification?
11. Which intelligence monitors/PIRs are active by watch area?
12. Can the same vessel record support both the Trade System and P&C Intelligence without duplication?
